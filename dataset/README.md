# Dataset Instructions

The IMDb 50k movie reviews dataset is excluded from version control due to its file size (66 MB).

### Download Steps:
1. Download the dataset from Kaggle:
   https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
2. Extract the archive and place `IMDB Dataset.csv` directly in this directory:
   ```text
   dataset/IMDB Dataset.csv
   ```
